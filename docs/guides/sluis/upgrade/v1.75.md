# Upgrade to v1.75

v1.75 removes secrets layout v3 and `transition`, and `sluis migrate secrets-layout`. Run `secrets.layout: v4` first; an installation still on v3 or `transition` moves on v1.74.x ([steps](../migrate/migrate-secrets-layout.md)).

## The Pulumi library

The first v1.75 apply adopts the v4 copies `sluis migrate` wrote and removes the `private/config` ones. The values are unchanged.

- The state secret and the recovery password are SSM parameters at `/sluis/<instance>/internal/config/issuer/state-secret` and `.../recovery/password`.
- The new parameters have `overwrite` set, so they adopt the copies that already exist, with the value from the same `RandomBytes` and `RandomPassword`.
- The old `private/config/...` parameters are removed from the program and deleted at the end of the apply, after the function is updated.
- The roles lose their grants on `private/*`.

Read the preview first: two parameters created, two deleted, no replacement.
