# Upgrade audit to v1.75

History is in the [CHANGELOG](../../../../CHANGELOG.md).

## Breaking changes

- `credentials_preset` needs `acknowledgeMinterCustody: true` in the chart's values, or `Args.AcknowledgeMinterCustody` in the Pulumi library. Otherwise the chart or the library refuses to render or build, naming the preset. Prefer to move the preset to `credentials_ref` ([put the archive on an S3-compatible store](../operate/archive-on-r2.md)), which needs neither.
