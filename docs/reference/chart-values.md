# Chart values

Every value of the `sluis` chart (`charts/sluis`), with its default. The chart is held to `charts/sluis/values.schema.json`,
which embeds the service document's schema under `config` and the policy document's under `policy`; `values.yaml` carries
the defaults and a comment per key. Why the chart is shaped this way, and the convention for naming Secrets, is in
[Configuration: the model](../explanation/configuration.md). The service document's own keys (`config.*`) are in
[Configuration](configuration.md).

| Included (standard Kubernetes APIs) | Expected to exist |
|---|---|
| Deployment, Service, ServiceAccount, a namespaced Role/RoleBinding (with the Kubernetes store), a cluster-scoped TokenReview role (with recovery), NetworkPolicy, the policy document and the service document as ConfigMaps, a Gateway and two `HTTPRoute`s (one for the issuer's own endpoints, one for the console's path), and, only where a `push` block is written, External Secrets `PushSecret`s | the Secrets a declared workspace, a declared OAuth client or an externally delivered signing key name; a Valkey, when `config.valkey` is set; External Secrets and the store each `push` block names |
