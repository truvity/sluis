# Chart values

Every value of the `sluis` chart (`charts/sluis`) with its default, held to `charts/sluis/values.schema.json`. The `config.*` keys are in [Configuration](configuration.md); the model is in [Configuration: the model](../../concepts/sluis/configuration.md).

| Included (standard Kubernetes APIs) | Expected to exist |
|---|---|
| Deployment, Service, ServiceAccount, a namespaced Role/RoleBinding (with the Kubernetes store), a cluster-scoped TokenReview role (with recovery), NetworkPolicy, the policy document and the service document as ConfigMaps, a Gateway and two `HTTPRoute`s (one for the issuer's own endpoints, one for the console's path), and, only where a `push` block is written, External Secrets `PushSecret`s; with `backup.enabled`, a CronJob each for the backup and the prune and an account of their own; with `restore.enabled`, one Job and an account of its own | the Secrets a declared workspace, a declared OAuth client or an externally delivered signing key name; a Valkey, when `config.valkey` is set; External Secrets and the store each `push` block names |

## Secret files

The chart projects each `secrets` entry, and in values mode each confidential client's Secret, as the file `<name>` in `/var/run/sluis/secrets`, mode 0440. The pod then runs as 65532:65532 with `fsGroup: 65532`, which also makes the other projected volumes group-readable.

## What the chart refuses

`charts/sluis/templates/_checks.tpl` and `_helpers.tpl` hold the checks. Each message names the value to change.

| Area | Refused |
|---|---|
| `secrets` | A name declared twice; `config.secrets` other than `{source: file, root: /var/run/sluis/secrets}` when the chart projects secrets |
| Documents mode | `documents.service` without `documents.policy`, or the reverse; either beside `policy`, `exchange.clusters` or `exchange.aws.accounts`; a document that is not YAML or has the wrong `apiVersion`; an adapter `settings.address` that is not https; a setting that holds a credential value instead of a name; a secret name the documents use (a policy client's `secret`, the Google OAuth client of `oauthClient.provider`, any `...Secret` field) that `secrets` does not declare, with `secrets.source: file` |
| Values mode | `exchange.clusters`, `exchange.aws`, `githubApps.catalogue` or `slackApps` set beside its `policy.*` counterpart |
| Controllers | No `exchange.clusters`; no `console.mount`; a `consoleURL` other than this release's own Service; `enabledOrgs` naming an organisation `policy.github` does not bind; `enabledWorkspaces` naming a workspace `policy.slack.workspaces` does not declare |
| `replicaCount` | Above 1 with a controller on, unless the State adapter is `dynamodb` |
| `push` blocks | Without `config.store: kubernetes`, a `secretStore` or a `remoteKey`; two pushes to the same `remoteKey` in one store; `slackState.push` without `recordsRemoteKey` |
| Route | `config.secureCookies: false` with `route.host`; a `publicRootURL` other than `https://<route.host>`, or a `publicURL` other than that plus `console.mount`, when `console.mount` is set; a `parentRefs` entry without `name` |
| Recovery | `config.recovery.enabled` without `config.inCluster: true`, `recovery.serviceAccount` or `recovery.audience` |
| Signing key | A key file (`config.signingKey.file`, `signingKey.additional`, `signingKey.existingSecret`) when signing is KMS; two keys for one algorithm; a private key in `signingKey.verifyOnly` |
| `telemetry.otlp` | An `endpoint` that is not http(s); `extraEnv` holding `OTEL_EXPORTER_OTLP_ENDPOINT` or a name not starting with `OTEL_` |
