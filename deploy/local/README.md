# The local installation

Docker Compose on one workstation, for development, continuous integration and the integration tests.
The walk-through, the recipes, the images, the host names, TLS and the first start are on one page:
[docs/runtimes/local.md](../../docs/runtimes/local.md) (<https://sluis.id/runtimes/local/>).

Run it inside devbox from the repository root: `devbox run -- just local-up`, then `just local-down`.
`compose.yaml` and `init.sh` are generated by `just compose-gen`; do not edit them.
